# 页面覆盖 · 冲突裁决面板（PRD 10.2.2 · U2 / 授信审查岗）

## 核心原则

**并列两个取值，等权重呈现。** 两个候选在表格与单选中**视觉同权**
（同样的行高、字号、边框），不用排版暗示哪一个"更可信"。

> 默认选中依 PRD 10.2.2 线框（● 取值 A）保留——PRD 是基线；
> 「等权重」约束的是呈现，不是禁掉线框里的默认勾选。
> 若产品侧决定去默认选中（防锚定），应**先改 PRD 线框**再改实现（评审 R-F13）。

## 区块

1. 字段名（等宽）+ 当前状态徽标「已拦截，未进入判定链」（琥珀）
2. **取值 A / 取值 B 双栏**：取值（等宽）+ 来源通道 + 置信度 + 定位（页码/区域）
3. 提示条：两路抽取不一致 → 该字段已被拦截 → 相关规则置「未判定」
4. **裁决表单**：单选（两值）+ 理由（**必填**，无理由不允许提交）+ 影响范围提示
5. 底部：`提交裁决`（主色实心，唯一）

## 本页专用规则

- 提交前必须填理由；未填时禁用按钮并给出**就近**的错误提示（不只放在顶部）
- 裁决后展示「该字段将回填为高置信，并触发相关规则重算」的**后果说明**
- 低置信字段列表用左侧琥珀竖条标出，不与正常字段混排
