# 页面覆盖 · 贷后预警池（PRD 10.2.3 · U4 贷后管理岗）

## 区块

1. **筛选条**：全部 / 高 / 中 / 低（等级用文字）+ 排序（提前量↓ · 命中时间↓）
2. **预警列表**：每条一行块
   - 预警号（等宽）+ 等级 + **提前量（等宽，突出）** + 触发规则编号版本
   - 触发事实（一句话 + 数值）+ 「证据快照已固化」标记
   - 核查结论 + 升级建议
   - **处置四档按钮组**（唯一主按钮为「触发现场检查」——四档里唯一会产生现场动作的）
3. 预警详情抽屉：完整证据快照 + 核查记录 + 签核记录

## 本页专用规则

- **提前量是贷后界面的主指标**，字号高于触发事实，等宽字体
- 触发规则必须显示**版本号**（如 `R-POST-007 v2.1.0`），与全项目版本口径一致
- 「证据快照已固化」用**图标 + 文字**，不只用颜色
- 四档处置**互斥单选**，选中态与未选中态差异明显
- 处置动作必须经 GATE-C：未签核时按钮区显示闸门状态与剩余时限，**不放行**
