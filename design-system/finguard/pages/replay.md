# 页面覆盖 · 案件回放时间轴（PRD 10.2.4 · U6 内审稽核岗）

## 区块

1. **时间轴**：案件号 + 节点序列（S0→…→S10），横向，可横向滚动
   - 闸门节点用 ⛔ 图标 + **不可跳过**（点击只展开说明，不提供"跳到下一节点"）
   - 已发生节点可点，展开当时的四类快照
2. **快照面板**：规则版本 / 文档依据 / AgentSpec / 事实快照（点击节点切换）
3. **导出区**：导出取证包 + **六层齐备性检查结果** + 导出 PDF / 导出结构化包

## 本页专用规则

- 六层齐备性检查结果用 ✓ / ✗ + 文字（缺哪一层要写出来），不只给一个色块
- 时间轴上**闸门节点与普通节点视觉上必须不同**（形状 + 颜色 + 文字三重）
- 快照面板里的规则版本必须是**当时**的版本，不是当前版本——这是回放的意义
- 导出 PDF 需要打印样式：浅色底、隐藏导航与操作按钮
