# 页面覆盖 · 审查意见工作台（PRD 10.2.1 · U2 合规审查岗）

覆盖 MASTER 的部分：区块顺序与「人机分层」。

## 信息层级（从上到下，顺序不可调换）

1. **案件头**：案件号 / 产品 / 机构 / 发生日 + 适用规则版本摘要 + 规则总数
2. **覆盖度条**：已判定 / 不适用 / 未判定 三段 + 未判定原因码（琥珀）
3. **意见卡片列表**：每条一张卡（规则编号版本 → 理由 → 事实引用表 → 依据出处 → AI 段落 → 人工操作区）
4. **待办区**（琥珀）：「须人工判定」清单 + 去处理按钮——**不可折叠默认收起**
5. **闸门条**（常驻底部）：⛔ GATE-A + 剩余时限 + 签核人资格 + 唯一主按钮

## 人机分层（本页最重要的一条）

- AI 产出的内容（理由 / 事实 / 依据）用**次级文字色 + 左边界线**标示为「AI 产出」
- 人工操作区用**主色实心按钮**，且**全页只允许一个**实心主按钮（提交签核）
- 按钮区必须标注当前动作由**人**执行，不出现任何「自动签核」入口

## 本页专用规则

- 严重度徽标用**文字**（提示 / 关注 / 重要 / 重大），不只用颜色
- 未判定规则用琥珀标签「须人工判定」+ 原因码（NO_VERSION_MATCH / AMBIGUOUS_VERSION）
- 事实引用表三列：字段路径（等宽）/ 取值（等宽）/ 来源 + 置信度
- 依据出处必须显示**文档号 + chunk + 生效日**，不能只显示文件名
